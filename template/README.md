# Game template — Phaser 4 + Vite (portrait 9:16)

Systems starter for ten gameplay families — mid-core indie genres
(survivor-like / roguelike / tower defense / deckbuilder / auto-battler /
tactics / racing) and casual ones (board puzzle / idle tycoon / table-dice /
word / hypercasual) — with 5-10 minute sittings and meta progression, a full
**generated art set** in vibrant 2D chibi style, generative music, a headless
balance simulator, and eight playable gameplay slices.

```bash
npm install
npm run dev      # http://localhost:5173
npm run sim      # headless balance sim + design gates for this game's family
npm run sim -- --family board   # a specific family's gates
npm run verify   # typecheck + sim gates + art-registry check + kit selftests
npm run build    # typecheck + dist/
```

- Internal resolution 720x1280, scaled `FIT` + centered — the TikTok / Reels /
  Shorts frame. Movement on a floating on-screen thumb stick, full keyboard
  parity (WASD / arrows), on-screen pause button + overlay.
- Systems included: bounded arena with impassable props, authored-layout
  support (`ArenaLayout` — the map-forge landing point) and a following camera;
  stat/modifier builds; health/crit/DoT with pause-safe i-frames; object pools;
  spatial hash broad phase; BFS flow-field navigation; declarative wave
  director with spawn patterns and scripted events (chest / breather /
  elite-rush); weapon system (bolt / orbit / nova / rail + evolutions) with an
  upgrade pool of stat, weapon and legendary effect cards + one-per-draft
  reroll; 3-phase boss; versioned meta save with a permanent-upgrade shop;
  seeded, reproducible runs (seed shown on the results screen).
- Family systems on top of that: `SessionDirector` contract with four
  directors (run / level / ramp / lap), a headless board engine
  (`core/board/*`: match-swap, blast, blocker layer, in-level boosters, low-move
  mercy, merge chains, sort, block-fit), an idle `Economy` (generators,
  managers, prestige, offline accrual), and a shared meta-kit — stars, daily
  streak, collections, uncapped boosters, saga map, pre-level booster picker and
  in-level booster tray.
- Genre kits (dormant until a PRD needs them, and the whole of family D): turn
  manager, deck/energy, deterministic auto-battle resolver, tap-to-place with
  ghost preview + path-validity, drag-drop board, card hand, shop tray.
- Audio needs no files: `sfx()` synthesises effects, `core/music.ts` plays
  generative layered music (menu/run moods, intensity, boss layer).
- Balance lives in `TUNING` (`src/config.ts`, arena) or the slice's
  `tuning.ts`, and is *verified*, not asserted: `npm run sim` runs the family's
  own bots/solvers — arena bot lanes, board greedy-vs-random solver ladder,
  hyper skill sweep, idle economy curves, table dice band, word bank integrity,
  side generator validation, track lap completion — and fails the build when a
  hard gate breaks.
- Art lives in `public/assets/generated/`, generated by the `game-art` skill
  against `art/style.json`; `src/data/art.ts` is **generated** by
  `node scripts/gen-art-registry.mjs` from `art/manifest.json` + sprite
  metadata (never hand-edit; `--check` guards drift in `npm run verify`).
- UI chrome is drawn with primitives (`src/ui/primitives.ts`), not stretched
  images; the background supports up to 3 parallax layers with cover-fit.

Eight of the ten families ship a playable slice under `src/slices/<code>/`
(`game.ts` + `tuning.ts` + family data); `src/scenes/game.ts` re-exports the
active one. The arena slice — auto-attacking chibi mage on a 1440x2160 arena, 4
weapons with evolutions, 8 enemy archetypes (healing auras, telegraphed
charges), scripted chests/breathers/elite-rushes, a 3-phase boss finale,
coin-dropping elites, 480s wave timeline — is the reference implementation;
replace the block marked `BEGIN/END replaceable gameplay` in
`src/slices/arena/game.ts` and the data in `src/data/`.

## Families

One family per game. `src/scenes/game.ts` is a one-line re-export of the active
slice, and `scripts/new-game.sh <slug> "Title" --family <code>` prunes the
other slices, rewrites that re-export and writes `src/sim/family.ts` so a bare
`npm run sim` runs the matching gates. `--family` takes the slice name.

| Code | Genres | Session director | Slice | Sim gate |
| --- | --- | --- | --- | --- |
| A | survivor-like, roguelike, tower defense | `RunDirector` (`core/run.ts`) | `src/slices/arena/` | `--family arena` |
| B | match/blast, merge, sort, block-fit | `LevelDirector` (`core/level.ts`) | `src/slices/board/` | `--family board` |
| C | platformer, endless runner, physics launch | `LevelDirector` / `RampDirector` | `src/slices/side/` | `--family side` |
| D | deckbuilder, tactics, auto-battler | `RunDirector`, fight-indexed | no slice — compose the genre kits | none yet |
| E | racing, karts, drift circuits | `LapDirector` (`core/lap.ts`) | `src/slices/track/` | `--family track` |
| F | idle, incremental, tycoon | `Economy` (`core/economy.ts`), no session end until ascend | `src/slices/idle/` | `--family idle` |
| G | solitaire, dice, roll-and-move | `LevelDirector`, or the slice's own `DiceLoop` roll budget | `src/slices/table/` | `--family table` |
| H | word, anagram, trivia | `LevelDirector` | `src/slices/word/` | `--family word` |
| J | hypercasual score chase | `RampDirector` (`core/ramp.ts`) | `src/slices/hyper/` | `--family hyper` |
| I | hybrid pattern (not a family): casual core from J/B/F + meta-kit layers | the core's | the core's | the core's |

Every director implements `SessionDirector` (`core/session.ts`), stays
Phaser-free, and reports `SessionOutcome {won, reason}` plus `ResultStat[]` rows
for the results screen. Family **D** ships kits (turn manager, deck,
auto-battle resolver, placement, board, hand, shop tray) and selftests but no
starter slice and no family gate — a D game builds both.

Read `AGENTS.md` before editing — it is the build contract.

## Player platform

Every game inherits, with zero per-game work (and zero effect where the
browser lacks the API):

- **Installable + offline.** `public/manifest.webmanifest` + `public/sw.js`:
  add-to-home-screen, standalone portrait launch, cached play after the first
  visit; `index.html` stays network-first so a redeploy is picked up on the
  next online load. The worker registers in PROD builds only — dev is never
  cached.
- **Native feel.** Screen Wake Lock during sessions (`core/wake.ts`, armed on
  the first tap) and a short throttled vibration riding `shake()`/`hitstop()`
  in `core/juice.ts`.
- **Daily challenge + sharing.** `core/daily.ts` seeds every session; the
  menu's DAILY toggle pins today's seed, `?d=YYYY-MM-DD` reproduces it from a
  shared link, and the results screen's SHARE button sends score + link via
  the native share sheet (clipboard fallback).
- **Telemetry.** `core/telemetry.ts` fires the funnel events
  (`session-start`/`daily-start`/`win`/`loss`/`retry`/`share`) as GoatCounter
  events when the published page carries the snippet; silent no-op otherwise.
- **Sound needs no assets**: `sfx('hit')` and `startMusic('run')` synthesise
  everything. To ship real audio, drop files under `public/assets/audio/` and
  register them in `src/data/audio.ts` — that registry is the only switch,
  per entry; anything left out keeps its synthesised voice.

## Layout

```
index.html                    portrait shell + boot splash
art/style.json                art style contract (sprite-forge.style.v1)
art/manifest.json             asset plan per group (input to the registry generator)
public/assets/generated/      generated sheets, frames, GIFs, metadata
scripts/gen-art-registry.mjs  art/manifest + metadata -> src/data/art.ts (--check)
scripts/ts-resolve.mjs        Node resolve hook: run any src/*.ts headless
scripts/verify.sh             typecheck + sim + registry check + kit selftests
src/main.ts                   Phaser.Game config (scale, physics, scenes)
src/config.ts                 VIEW / SAFE / PALETTE / TEXT / TUNING / PLAYER_BASE_STATS
src/core/                     session (SessionDirector), run, level, ramp, lap,
                              board/ (grid, resolve, merge, sort, block),
                              economy, progression (meta-kit v2), collections,
                              stats, damage, pool, spatial, grid, controls,
                              juice, audio, music, textures, rng, storage,
                              keys, effects, turns, deck, autobattle, spritePool
src/data/                     art registry (GENERATED), enemies, weapons, upgrades,
                              waves (+ TIMELINE_EVENTS), props
src/objects/                  player, enemy, projectile, xporb, coin, blade
src/slices/                   one dir per family: arena, board, side, track,
                              idle, table, word, hyper — game.ts + tuning.ts
                              (+ levels/gen/content/stack/board/math)
src/systems/                  arena (field, props, layouts), combat (weapons, boss,
                              pools, broad phase), placement, board (+ boardMath)
src/ui/                       primitives, hud, bars, cards (reroll), button, joystick,
                              background (parallax), pauseOverlay, hand, shopTray,
                              sagaMap, boosterBar, coach (FTUE coach marks)
src/scenes/                   boot, preload, menu, meta, game (slice re-export),
                              gameover (ResultStat rows + meta award)
src/sim/                      headless balance sim: model, bots, metrics, cli,
                              family.ts (scaffolded default), families/*.ts
                              (per-family gates), kits/*.selftest.ts
```
