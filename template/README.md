# Game template — Phaser 4 + Vite (portrait 9:16)

Systems starter for complex indie-genre games (survivor-like / roguelike / tower
defense / deckbuilder / auto-battler / tactics) with 5-10 minute runs and meta
progression, a full **generated art set** in vibrant 2D chibi style, generative
music, a headless balance simulator, and a playable survivor-like slice.

```bash
npm install
npm run dev      # http://localhost:5173
npm run sim      # headless 480s balance sim + design gates
npm run verify   # typecheck + sim gates + art-registry check + kit selftests
npm run build    # typecheck + dist/
```

- Internal resolution 720x1280, scaled `FIT` + centered — the TikTok / Reels /
  Shorts frame. Movement on a floating on-screen thumb stick, full keyboard
  parity (WASD / arrows), on-screen pause button + overlay.
- Systems included: bounded arena with impassable props, authored-layout
  support (`ArenaLayout` — the map-forge landing point) and a following camera;
  stat/modifier builds; health/crit/DoT with pause-safe i-frames; object pools;
  spatial hash broad phase; BFS flow-field navigation; declarative wave
  director with spawn patterns and scripted events (chest / breather /
  elite-rush); weapon system (bolt / orbit / nova / rail + evolutions) with an
  upgrade pool of stat, weapon and legendary effect cards + one-per-draft
  reroll; 3-phase boss; versioned meta save with a permanent-upgrade shop;
  seeded, reproducible runs (seed shown on the results screen).
- Genre kits (dormant until a PRD needs them): turn manager, deck/energy,
  deterministic auto-battle resolver, tap-to-place with ghost preview +
  path-validity, drag-drop board, card hand, shop tray.
- Audio needs no files: `sfx()` synthesises effects, `core/music.ts` plays
  generative layered music (menu/run moods, intensity, boss layer).
- Balance lives in `TUNING` (`src/config.ts`) and is *verified*, not asserted:
  `npm run sim` replays full runs against bot lanes (including per-weapon
  builds) and gates winnability, losability, pacing and build dominance.
- Art lives in `public/assets/generated/`, generated by the `game-art` skill
  against `art/style.json`; `src/data/art.ts` is **generated** by
  `node scripts/gen-art-registry.mjs` from `art/manifest.json` + sprite
  metadata (never hand-edit; `--check` guards drift in `npm run verify`).
- UI chrome is drawn with primitives (`src/ui/primitives.ts`), not stretched
  images; the background supports up to 3 parallax layers with cover-fit.

The demo slice — auto-attacking chibi mage on a 1440x2160 arena, 4 weapons with
evolutions, 8 enemy archetypes (healing auras, telegraphed charges), scripted
chests/breathers/elite-rushes, a 3-phase boss finale, coin-dropping elites,
480s wave timeline — is a reference implementation.
Replace the block marked `BEGIN/END replaceable gameplay` in
`src/scenes/game.ts` and the data in `src/data/`.

Read `AGENTS.md` before editing — it is the build contract.

## Layout

```
index.html                    portrait shell + boot splash
art/style.json                art style contract (sprite-forge.style.v1)
art/manifest.json             asset plan per group (input to the registry generator)
public/assets/generated/      generated sheets, frames, GIFs, metadata
scripts/gen-art-registry.mjs  art/manifest + metadata -> src/data/art.ts (--check)
scripts/ts-resolve.mjs        Node resolve hook: run any src/*.ts headless
scripts/verify.sh             typecheck + sim + registry check + kit selftests
src/main.ts                   Phaser.Game config (scale, physics, scenes)
src/config.ts                 VIEW / SAFE / PALETTE / TEXT / TUNING / PLAYER_BASE_STATS
src/core/                     stats, damage, pool, spatial, grid, run, progression,
                              controls, juice, audio, music, textures, rng, storage,
                              keys, effects, turns, deck, autobattle, spritePool
src/data/                     art registry (GENERATED), enemies, weapons, upgrades,
                              waves (+ TIMELINE_EVENTS), props
src/objects/                  player, enemy, projectile, xporb, coin, blade
src/systems/                  arena (field, props, layouts), combat (weapons, boss,
                              pools, broad phase), placement, board (+ boardMath)
src/ui/                       primitives, hud, bars, cards (reroll), button, joystick,
                              background (parallax), pauseOverlay, hand, shopTray
src/scenes/                   boot, preload, menu, meta, game, gameover
src/sim/                      headless balance sim: model, bots, metrics, cli,
                              kits/*.selftest.ts
```
