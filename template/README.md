# Game template — Phaser 4 + Vite (portrait 9:16)

Systems starter for complex indie-genre games (survivor-like / roguelike / tower
defense) with 5-10 minute runs and meta progression, plus a full **generated art
set** in vibrant 2D chibi style and a playable survivor-like slice.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck + dist/
```

- Internal resolution 720x1280, scaled `FIT` + centered — the TikTok / Reels /
  Shorts frame. Movement on a floating on-screen thumb stick, full keyboard
  parity (WASD / arrows).
- Systems included: bounded arena with impassable props and a following camera,
  stat/modifier builds, health/crit/DoT, object pools, spatial hash broad phase,
  BFS flow-field navigation, declarative wave director, versioned meta save with
  a permanent-upgrade shop, in-run upgrade draft.
- Audio needs no files: `sfx()` synthesises every sound with WebAudio.
- All balance numbers live in `TUNING` in `src/config.ts`.
- Art lives in `public/assets/generated/`, generated by the `game-art` skill
  against `art/style.json` and registered in `src/data/art.ts`: entities, FX,
  icons, emblem, backdrop.
- UI chrome is drawn with primitives (`src/ui/primitives.ts`), not stretched
  images, so panels/buttons/bars fit any size and follow `PALETTE`.

The demo slice — auto-attacking chibi mage on a 1440x2160 arena, 8 enemy
archetypes, impassable props, XP orbs, level-up draft, 480s wave timeline with
elites and a boss — is a reference implementation.
Replace the block marked `BEGIN/END replaceable gameplay` in
`src/scenes/game.ts` and the data in `src/data/`.

Read `AGENTS.md` before editing — it is the build contract.

## Layout

```
index.html                    portrait shell + boot splash
art/style.json                art style contract (sprite-forge.style.v1)
art/manifest.json             asset plan per group
public/assets/generated/      generated sheets, frames, GIFs, metadata
src/main.ts                   Phaser.Game config (scale, physics, scenes)
src/config.ts                 VIEW / SAFE / PALETTE / TEXT / TUNING
src/core/                     stats, damage, pool, spatial, grid, run, progression,
                              controls, juice, audio, textures, rng, storage, keys
src/data/                     art registry, enemies, upgrades, waves
src/objects/                  player, enemy, projectile, xp orb
src/systems/                  arena (field, props, walls), combat (pools + broad phase + auto-attack)
src/ui/                       primitives (all chrome), hud, bars, cards, button, background
src/scenes/                   boot, preload, menu, meta, game, gameover
```
