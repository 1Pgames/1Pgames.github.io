# Duskhaul SFX: ElevenLabs text-to-sound-effects

Generated by Main with ElevenLabs text-to-sound-effects on 2026-09-26. Every prompt had this suffix appended:
`; grimdark dark-fantasy game sound effect, dry and close, crisp transient, no music, no voice, no reverb tail`.

The raw MP3s are in `raw/<voice>.mp3` (512 KB total). The shipped files are `public/assets/audio/sfx/<voice>.ogg`.

Processing steps (the `ffmpeg` decode and encode ran from a throwaway Node script):
1. Decode to mono, 44.1 kHz, float.
2. Trim the start to the first sample above −50 dBFS, minus 5 ms. Every file already started hot, so this removed 0 ms.
3. Trim the tail after the last sample above −50 dBFS, then apply a 20 ms linear fade-out.
4. Apply gain so the file's maximum momentary loudness (EBU R128 M, 400 ms window) equals the matching synth voice rendered at volume 1. The gain is capped so the peak stays at or below −1 dBTP. `die` and `nova` hit the cap, and `sampleGain` in `core/audio.ts` VOICES makes up the rest.
5. Encode as OGG Vorbis, `-q:a 3`.
