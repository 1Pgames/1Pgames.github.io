Tonal and world beats whose sound IS a tail (pads, siren, bellow, cello, organ, launch) used a shortened suffix so the model would not cut them dry; the exact suffix is given per row (**S2** = `; 1970s retro sci-fi colony game sound effect, no music, no voice` with small per-row wording noted in the prompt column).

Shipped: `public/assets/audio/sfx/<voice>.ogg`; signature options `public/assets/audio/sfx/options/<voice>-<A..C>.ogg`.

## Processing

`node art/briefs/sfx-elevenlabs/process.mjs` (run from the game root) does every step and writes `results.json`:

1. Decode to mono, 44.1 kHz, float.
2. Trim the head to the first sample above −50 dBFS minus 5 ms, the tail after the last sample above −50 dBFS, then a 20 ms linear fade-out.
3. Gain so the file's max momentary loudness (EBU R128 M, 400 ms, ffmpeg `ebur128`, 0.5 s silence padded so short files fill a window) equals the voice's synth fallback rendered offline at volume 1 from the `VOICES` table in `src/core/audio.ts` (the script lifts `prd()` + `VOICES` from that file, so the reference cannot drift from the engine). Gain is capped so the peak stays ≤ −1 dBTP; after encoding, a file whose Vorbis true peak overshoots −1 dBTP is re-encoded with the gain pulled down.
4. Encode OGG Vorbis `-q:a 3`.

Where the cap withheld loudness, `sampleGain` on the voice in `core/audio.ts` makes it up: `fail` 2.19, `lander` 1.43 (for option A — option B would need 2.88, C needs none), `pick` 1.12.

Synth reference note: band-passed noise rows in PRD §12 originally measured 15–25 dB under tonal rows at the same `gain` (launch −37.6, flak −47 M), which would have matched big beats to near-silence. `prd()` now lifts each noise layer to ~0.7 RMS per unit gain (×16 max); the references below are after that fix.
